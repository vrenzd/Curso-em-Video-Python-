Este repositório contém os exercícios, desafios e projetos desenvolvidos durante o curso de Python ministrado pelo professor Gustavo Guanabara no canal [Curso em Vídeo](https://www.cursoemvideo.com/). O curso é dividido em três módulos (Mundos), cada um com foco em diferentes aspectos da linguagem Python.

---

##  Sobre o Curso

O curso é voltado para iniciantes e cobre desde os fundamentos da linguagem até conceitos mais avançados como estruturas de dados, funções e manipulação de arquivos. Cada mundo é composto por aulas teóricas e práticas, com desafios que estimulam o raciocínio lógico e a aplicação dos conceitos aprendidos.

---

##  Estrutura do Curso

### Mundo 1 - Fundamentos de Python
- Introdução à linguagem e instalação do ambiente
- Tipos primitivos: `int`, `float`, `bool`, `str`
- Operadores aritméticos e lógicos
- Entrada e saída de dados
- Manipulação de strings
- Condições `if`, `else`, `elif`
- Desafios práticos (ex: cálculo de média, verificação de maioridade, etc.)

### Mundo 2 - Estruturas de Controle
- Laços de repetição: `for`, `while`
- Interrupção de laços com `break` e `continue`
- Uso de `range()` e controle de fluxo
- Interação com o usuário
- Desafios práticos (ex: tabuada, contagem regressiva, jogos simples)

### Mundo 3 - Estruturas Compostas
- Listas, tuplas e dicionários
- Manipulação de coleções
- Funções e modularização
- Tratamento de erros com `try/except`
- Leitura e escrita de arquivos
- Desafios práticos (ex: cadastro de pessoas, análise de dados, mini sistemas)
